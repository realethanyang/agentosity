# 下班榜 · 项目由来与发展

> 产品名:下班榜
> Slogan:全国上班族共同维护的真实下班时间数据库
> 起点:VibeHacks #5(24 小时黑客松,主题「早点下班」)

---

## 一、起头:一个"做不出来"的主题

2026-08 下旬,Vibe Cafe 举办 **VibeHacks 第 5 期**,24 小时黑客松,主题是**「早点下班」**。

一开始我把这个主题当成一个普通的"效率工具命题",列了一堆方向:一键收工 Agent、会议终结者、周报生成器、下班保护盾……但每一个都被否掉——不是没技术含量,就是做出来没用,或者总感觉"怪怪的"。

随后想到的"夜班 Agent"(你 6 点下班、把活交接给 AI 夜班同事继续干),虽然听起来不错,但对我自己而言毫无新意:我已经做过 LoopHouse(一套多 Agent 编排系统),而"让 Agent 晚上挂着跑"在技术上没有任何门槛,谁都能做。而且拿一个"我自己已有产品上的功能迭代"去参赛,感觉也别扭。

## 二、想通的那个坎:"早点下班"是政治问题,不是产品问题

真正卡住我很久的,是这个主题本身的结构性矛盾:

- 老板**不**让你早走 → 任何"帮你早下班"的工具都是在和老板对抗,关系搞僵,没人会用;
- 老板**允许**你早走 → 那这个问题根本不存在,不需要工具。

所以凡是在"对抗加班文化"上做文章的东西,放在国内"内卷"的语境里都别扭。**这不是点子的问题,是"给这个主题做工作工具"这条路本身是死路。**

## 三、研究:黑客松赢家的真相

为了找灵感,我去翻了 VibeHacks 前几期和国内其他小型黑客松的获奖作品,发现一个反直觉的规律:

- VibeHacks #02(播客):一等奖《关注"主播"》、二等奖《Radio Gaga》(给父母做实体收音机)
- VibeHacks #04(1 分钟小游戏):《一分钟拼图》《妈妈回来前一分钟》、12 岁和 10 岁兄妹做的《一分钟劫匪》
- 小红书黑客松:Pocket Guitar、初中生团队做的《薯医 NoteRx》
- TRAE 大赛:前保安为自己颈椎痛做的《动动脖子》
- 卖客松:13 岁女孩做的《在场》虚拟陪读

结论:**赢的从来不是"技术最新/最难"的东西,而是"有人味、和创作者自己有关、demo 干净"的东西。** 3 分钟 demo 让人记住,胜过证明技术能力。

## 四、破题:下班打卡排行榜

想通"别做工作工具、做能让人记住的东西"之后,灵感来了:**做一个下班打卡器 + 公司排名 + 只公布前三名。**

核心机制是"**把内卷这个引擎原地反转**":

- 排名、攀比、面子——这些平时逼你加班的机制,现在反过来逼大家抢着**早走**;
- **只公布前三名、不公布倒数**——只有正面激励,没有负面羞辱;
- 每个打卡者第二天收到**私信**:自己公司排第几,"离进前三还差 X 分钟"。

这个"只公布前三"的设计是灵魂:它让"谁下班早有面子"这件事自己滚起来,还天然规避了"太晚丢脸 / 老板觉得丢脸"的问题。

## 五、一路加进来的东西(讨论演进)

- **分行业、分城市榜单**:不是多个榜那么简单,而是放大了整个传播循环——"全国第一"之外还有"XX 行业第一""上海第一",更多公司有机会上榜,私信里的"距离前三"也更够得着;
- **Agent 加班榜**:后来衍生出的差异化爆点——"Agent 在替你加班,所以你才能早下班"。通过 MCP 让 Agent 自动打卡,证明"公司越 AI-native,人走得越早";
- **Neo Brutalism 视觉**:粗边框、硬阴影、高饱和色块,自带反精致、戏谑的气质,和"反内卷"的调性天生一对;
- **名字与域名**:从"下班王"最终定名**「下班榜」**,slogan 定为"全国上班族共同维护的真实下班时间数据库"。

## 六、Agent 侧的深挖与升维:Agentosity 的诞生(2026-08-27 讨论)

动工前把"Agent 加班榜"这个副线单独拎出来深聊了一轮,结果它长成了整个项目的第二条主线:

- **推翻了原采集方案**:原设想靠 prompt 让模型自己调 agent_start/agent_end 打卡,聊透之后发现根本不成立——会话结束时模型不会被唤醒,agent_end 必然丢;考勤不能靠被考勤者自觉。定稿方案反转思路:**不让模型打卡,让 server 感知生命周期**——本地 stdio MCP 进程被 harness 自动拉起/杀掉,进程生死就是考勤信号(心跳为准、遗言为辅),再叠"文件探针"(watch 各 harness 本地会话文件的 mtime + 尾巴状态 + 进程树)把"在岗时长"精化成"活跃时长",解决挂机虚高和长工具调用误判两个数据可信度问题;
- **查了竞品,没有撞车**:最近的邻居是 claudeusage.com / ccgather.com / ccusage 这类"个人晒 token 消耗"的榜,无公司维度、无"Agent 替你加班"叙事;百度在推 DAA 概念但没人真测——"大佬在喊,我们在测";
- **指标体系定名**:基本单位 **agent-hours**(对仗 man-hours/GPU-hours),Active Agent-Hours(主指标)、DAA/MAA、Agent Overtime、**Agent Leverage**(agent-hours ÷ human-hours);
- **升维命名**:从"下班榜的副功能"升维成"衡量个人/组织 AI-native 程度的标尺"。造词过程:先想到 agentivity(可惜 .com/.ai/.io 全被抢注),顺着 -osity/-ivity/-icity 这族量纲后缀(luminosity/viscosity/conductivity)造出 **Agentosity**——agentosity.com 查时可注册且只要 ~$10,暂定为英文/全球品牌,中文"下班榜"继续用于国内;
- **Slogan 定稿**:**"AI-native is a number now."**(主,把人人自称的形容词变成可测量的数字)+ "Humans clock out. Agents clock in."(副,情绪担当);
- **产品形态展开**:人类打卡的高频动作从 Web 挪到 **macOS menu bar app**(SwiftUI MenuBarExtra,图标徽标实时显示活跃 agent 数,popover 一键打卡,兼任探针宿主);**CLI 是一等公民**(`npx agentosity`,mac/Windows/Linux 全功能一致,Windows 不缺席);登录改为无密码邮箱(magic link / 设备授权流);评估过 GPUI(Zed 的 GPU 渲染 UI 框架),结论是与我们这种小面板 UI 无关,不采用。
