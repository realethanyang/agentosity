# 产品改版方案 v1(定位:Agentosity 为核,下班为对照)

> 定位(已定):Agentosity = AI 时代的考勤系统。自动测量 Agent 工时,让"AI 替人扛了多少活"
> 成为可测量、可比较、可炫耀的数字;人类下班时间是它最有人味的注脚。

## 一、命名与文案系统

| 位置 | 内容 |
|---|---|
| 产品正名 | **Agentosity**(中文场合口称"下班榜"保留为 campaign 名) |
| 网页 title | `Agentosity — AI-native is a number now.` |
| 主 slogan | AI-native is a number now. |
| 副 slogan(人味) | Humans clock out. Agents clock in. |
| 中文主标语 | 方案 A:「AI 时代的考勤系统」(宣言式) / 方案 B:「你的 Agent,今天干了几小时?」(问句式)【待选】 |
| CTA 动词 | Measure your Agentosity / 接入考勤 |

## 二、Web 信息架构:四页收成三页

导航:**仪表盘(/) · 榜单(/leaderboard) · 我的(/me)**(登录入口在右上角)

### /(首页)= 实时仪表盘,回答"此刻世界在发生什么"
1. Hero 大数字:**⚡ N 个 Agent 正在干活**(全网,实时)+ 今日累计 agent-hours 滚动数 + slogan;
2. **灵魂对照条**:🏃 今天已有 X 位人类下班 · 他们的 Agent 还有 Y 个在岗(把两本账焊在一句话里);
3. Agent 加班榜 Top5 预览 → 去 /leaderboard;
4. 早下班英雄榜 Top3 小卡(人味对照)→ 去 /leaderboard;
5. 接入 CTA(下载 App / 一条命令,按平台分流);
6. 登录后追加:你的今日战报 mini 条。

### /leaderboard(榜单页)= 双榜合一,主次分明
- **主 Tab:Agent 加班榜** — 列:Rank / 公司 / **Active Agent-Hours(主排序,大字)** / DAA / Agent Overtime / Leverage / **人类平均下班(新列)** / 在岗 ⚡😴。
  - "人类平均下班"这一列是灵魂落点:同一行里"人走 18:05 · agent 干到 23:40",不用任何解释叙事自现;
  - 列头带一句话 tooltip(指标可解释);
- **次 Tab:早下班英雄榜** — 保持只公布前三 + 三数卡;
- 行业/城市标签筛选放本页(两个榜共用)。

### /me(我的)= 个人主页,合并原 /checkin + /me
- 今日打卡状态 + 一键打卡(打卡动作收进"我的");
- 我的公司揭榜排名(私密)+ 距前三差距;
- 我的 Agent 今日战报(active/在岗/live);
- 公司绑定管理(唯一改绑入口)+ 账号管理。
- 原 /checkin 保留为独立**极简快速打卡页**(现场扫码场景专用,导航不露出)【待确认】。

### /start(新增,轻页)= 接入与信任
- 下载 App / 一条命令(平台分流,从 /agents 迁来);
- 支持的 harness 列表 + 探针精度说明;
- **原理与隐私承诺**(只报时长、不读内容、开源可审计)——信任故事值得一个正式的家;
- /agents 路由 301 到 /leaderboard。

## 三、Menu bar App 信息重排

顺序原则:**个人 > 对照 > 全网**(现状反了)
1. 品牌行(不变);
2. **你的今日战报**(⚡ 你的 Agent 干了 X 小时,升为第一卡);
3. **个人对照行(新)**:✅ 你 18:05 已打卡 · 你的 Agent 还有 N 个在岗——灵魂在个人尺度的复刻;
4. 全网实况(黑卡,降为第三位);
5. 打卡按钮 / 接入折叠 / footer(不变);
6. 菜单栏图标徽标:登录后显示**自己的** working 数,未登录显示全网【待确认】。

## 四、砍掉的杂音
- 首页不再以人类榜开屏(它去 /leaderboard 次 Tab);
- /agents 页拆解:实况→首页,榜→/leaderboard,接入→/start;
- 导航四项 → 三项;menu bar 不新增元素只重排。

## 五、落地成本
全部为现有组件重排 + 一个新列(人类平均下班,SQL 现成视图 join)+ 一个新轻页(/start)。
估 2-3 小时,不动数据层。
