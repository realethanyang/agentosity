# 用户路径(动线定稿)

> 一句话:**账本在云端;网页负责看和管;mac 用 App 一站全包;其他平台三行命令。**
> 产品统一登录(无密码邮箱验证码);demo.agentosity.com 豁免登录,供现场演示。

## 三个组件的角色

| 组件 | 角色 | 比喻 |
|---|---|---|
| 服务端(Supabase + Vercel) | 考勤账本:人类下班账 + Agent 工时账 | 账本 |
| 网页 agentosity.com | 看(揭榜/Agent 榜/我的排名)+ 管(登录、公司绑定=唯一真相、改绑每周一次)+ 手机打卡 | 营业厅 + 公告栏 |
| CLI `npx agentosity` | 接入器:init 一次自动配置六家 harness 的 MCP 考勤;radar 收编存量会话;跨平台 | 装电表的师傅 |
| mac 菜单栏 App | 显示屏 + 打卡机 + 一键接入(复用 CLI)+ 📡 雷达 | 全家桶 |

## 四种画像

1. **mac 用户(黄金路径)**:下载 App → 登录(跳浏览器授权)→ 网页绑公司 → 完事。雷达自动收编本机全部 Agent 会话;想要协议级精度点"一键接入"。零终端。
2. **非 mac / 终端派**:三行命令(login 收码 → login 验码 → init)。Agent 考勤全精度;`radar` 补存量(unix);打卡用 `clockout` 或网页。
3. **未登录访客**:网页和 App 都是只读橱窗——看榜自由,打卡/接入/雷达需登录。
4. **demo 现场观众**:demo.agentosity.com 扫码即打卡,零门槛(模拟数据世界,不污染正式账本)。

## 采集架构(三个可插拔传感器,同一上报契约)

- **MCP 考勤进程**(主):harness 拉起即上班、杀掉即下班;心跳为准、遗言为辅;探针测活跃(文件 mtime / 尾巴在途 / 子进程基线 / CPU 增量)。
- **进程雷达**(补盲区):App 内建 / CLI `radar`;扫进程表补录无 MCP 考勤的会话;已有 MCP 的自动跳过;App 与 CLI 雷达互斥。
- **OTEL 精确模式**(roadmap):Claude Code 官方遥测,企业级精度。

## 身份模型

- 每端一个匿名设备身份;登录(任一端)即把该设备历史并入账号(同日打卡冲突保留更晚一次)。
- 公司绑定存服务端(profiles),首绑免费、改绑每周一次;打卡不接受客户端指定公司。
- 会话 token 1 小时过期,全端 refresh token 自动续期。
